A PRACTICAL GUIDE

A little help,
when you need it.

Everything you need to start using GatherShelf on distribution day.

01 / STOCK

Set up your shelf

Add each item and the number of whole units available. Use separate stock entries when units or dates differ. The optional date is there to support your review; it does not determine food safety.

02 / REQUESTS

Record what people choose

Create a request with a short reference and the quantities a household actually asks for. Use a non-identifying reference if possible. A pantry volunteer should verify food labels, allergies and the suitability of every item.

03 / PACKING

Review, then record

Open Packing to see each household’s requested and available quantities. When stock is short, whole units are shared proportionally to each household’s request for that item; ties use a stable request ID. Review the plan with your own pantry rules. Recording the distribution subtracts the quantities packed and keeps unfilled requests.

04 / BACKUP

Keep a copy

Records live in this browser on this device. They do not sync to another phone or computer. Export a backup before clearing browser data or switching devices. Store backups securely: anyone with the file can read its contents.

Good to know

This workspace is intended for one device at a time. It is not a food safety, allergy, nutrition or eligibility assessment. Never substitute a suggested allocation for a volunteer’s judgment.
